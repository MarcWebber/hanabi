# 只属于我们的烟火

一个直接使用 Three.js 构建的实时 3D 烟花原型。场景是一座湖畔双人观景台，包含程序化烟花、辉光后期、文字烟花、六种预设图案、手绘图案、四套配色、自动烟花秀和可选声音。

## 运行

```bash
npm install
npm run dev
```

打开终端显示的本地地址即可。点击夜空可以在指定位置发射烟花，拖动视角可以环顾场景；右下角的烟花创作台可以输入文字、选择图案或直接手绘。

## 技术

- Three.js 直接管理场景、镜头、粒子与角色
- Unreal Bloom 后期辉光
- Canvas 采样生成文字与手绘粒子形状
- Web Audio 实时合成升空和爆炸声
- vinext / React 页面外壳
