# Recorded firework samples

These nine Ogg files are selected from **25 CC0 bang / firework SFX** by
rubberduck:

- Source: https://opengameart.org/content/25-cc0-bang-firework-sfx
- License: CC0 1.0 Universal / Public Domain
- Original files: `fw_01.ogg` through `fw_06.ogg`, plus
  `cannon_01.ogg` through `cannon_03.ogg`

The project layers the recordings with procedural launch, sub, crackle and
reverb components in `src/fireworks/audio/FireworkAudio.ts`.
