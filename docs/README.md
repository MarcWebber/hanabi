## 当前维护边界

- 保留线上体验与仓库，不执行 GitHub Archive。
- 不再主动扩张场景数量、烟花类型或摄影参数。
- 必要时仍可修复浏览器兼容、构建失效、资源链接和许可归属问题。
- 当前版本是一个完成的个人作品，不承诺长期路线图或固定发布周期。

如果只是想体验花火，不需要阅读开发文档：打开 [线上版本](https://hanabi-sage-beta.vercel.app)，点击画面启用声音，然后抬头看夜空即可。
