# 摄影机制

花火的摄影模块是一套实时 WebGL 摄影模拟。它遵循常见相机参数之间的关系，但最终输出仍是浏览器渲染的 PNG，不等同于真实相机的 RAW 文件或完整光学仿真。

## 一次快门怎样完成

按 `Enter`、`S` 或“释放快门”后，系统依次执行：

1. 播放开帘反馈并锁定当前视角。
2. 在设定的物理快门时间内采集每个已渲染画面。
3. 将这些画面写入一张全新的曝光底片，使用运行平均完成多帧积分。
4. 到达快门时间后停止采样，播放关帘反馈并生成 PNG。
5. 暂停实时场景，进入照片回看。

每次曝光都使用独立底片，不会继承上一次的历史画面。静止的城堡因此保持清晰，运动中的烟花则会沿轨迹留下连续光迹；这与把整张屏幕持续做指数残影是两种不同的效果。

快门范围为 `1/1000 s` 至 `8 s`。当快门快于显示器的一帧时，浏览器只能记录下一张实际渲染帧；界面仍会保留短暂的机械开合反馈。长于一帧的曝光按墙钟时间持续采样，关帘动画和 PNG 编码发生在物理曝光之后，不计入快门时间。

## 参数含义

| 参数 | 实际作用 |
|:--|:--|
| 焦段 | 改变透视相机的视场角；数值越大，取景越窄，烟花看起来越近 |
| 光圈 | 按平方关系影响曝光，并参与薄透镜近似的景深计算 |
| 快门 | 影响曝光级数，并决定多帧采集窗口的真实持续时间 |
| ISO | 提升整体曝光，同时增加暗部优先的亮度噪声与轻微彩色噪声 |
| 对焦距离 | 指定焦平面与相机之间的场景距离，配合焦段和光圈决定虚化量 |
| 镜头辉光 | 控制高光扩散强度，是艺术化的镜头表现，不是曝光三要素 |
| 滤镜 | 调整色温、饱和度、对比度、暗角与黑位抬升 |

曝光表以 `28 mm · ƒ/4 · 1/60 s · ISO 320` 为基准计算 EV 差值。ISO 25600 的“高感”预设会刻意呈现接近白昼的亮度和显著传感器噪声；普通 ISO 下噪声会明显收敛。

## 预设

| 预设 | 适合的画面 |
|:--|:--|
| 长曝光 | `1 s` 光轨，城堡焦平面稳定 |
| 夜景 | 平衡亮度与噪声的实时取景 |
| 高感 | 验证极高 ISO 的亮度与噪声表现 |
| 浅景深 | 近处烟花或局部主体，背景自然离焦 |
| 暖色 | 50 mm 玫瑰调色的人像式构图 |
| 长焦 | 压缩城堡与烟花之间的视觉距离 |

## 模拟边界

当前版本不会模拟 RAW、拜耳阵列解码、镜头畸变、衍射星芒、果冻快门或真实传感器读出电路。景深来自深度缓冲后的 Bokeh 后期处理，噪声由着色器根据 ISO、亮度和像素位置实时生成。它的目标是提供可信、可操作的摄影感知，而不是替代光学或相机工程软件。
