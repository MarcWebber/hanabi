# 使用指南

## 开始观赏

打开 [花火](https://hanabi-sage-beta.vercel.app) 后，等待月港场景载入完成。浏览器需要一次主动点击才能启用音乐与烟花声；建议使用耳机并全屏观看。

视点位于城堡露台的人眼高度。拖动夜空可以转动视线，点击夜空会在当前目光所指的位置发射一束烟花。

## 场景工具

| 入口 | 用途 |
|:--|:--|
| 场景 | 在月港、蔷薇露台与观星台三种实时灯光氛围间切换 |
| 音乐 | 播放内置夜曲、调节音量或载入本地音频 |
| 音效 | 开启或关闭升空、爆炸、回声与环境声 |
| 自动 | 持续轮换图案、配色、升空方式与消散效果 |
| 演出 | 播放六幕、约 78 秒的预设烟花秀 |
| 摄影 | 打开摄影参数与照片回看界面 |
| 全屏 | 让夜景占满当前显示区域 |

## 创作一束烟花

点击右侧的“花”打开烟火编辑器。创作台包含四类内容：

1. **文字与图案**：输入短句，或从牡丹、菊型、爱心、土星环、垂柳、星星、螺旋、蝴蝶、棕榈、皇冠、双环和流星中选择轮廓。
2. **自由手绘**：在 `960 × 560` 画板上绘制轮廓，系统会将有效像素采样为粒子位置。
3. **效果参数**：调整颜色、爆炸强度、散开程度、停留时间、拖尾长度、升空方式与消散形态。
4. **烟花组**：逐条添加图案与间隔、拖动排序，再按既定顺序播放整组演出。

文字和手绘图案都在浏览器中即时采样，不是预先录制的视频。

## 摄影与保存

按 `⌘ P`（Windows/Linux 为 `Ctrl P`）进入摄影模式。选择预设或自行调整参数后，按 `Enter`、`S` 或界面的“释放快门”。曝光结束后会自动暂停画面并打开照片回看，可返回取景或保存 PNG。

长曝光期间请保持视点稳定。相机会在按下快门后锁定视角，避免建筑因操作产生不自然的重影。摄影计算方式见 [摄影机制](./PHOTOGRAPHY.md)。

## 快捷键

| 快捷键 | 作用 |
|:--|:--|
| `⌘ P` / `Ctrl P` | 进入或退出摄影模式 |
| `Enter` / `S` | 释放快门 |
| `Space` | 暂停或继续实时画面 |
| `R` | 视线回到初始方向 |
| `Esc` | 关闭照片回看；没有回看时退出摄影模式 |

快捷键不会在输入框、选择器或按钮获得焦点时抢占输入。
